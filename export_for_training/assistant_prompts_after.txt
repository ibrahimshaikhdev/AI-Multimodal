# Project overview
This is the Multimodal AI Research & Medical Report Intelligence platform, a Flask web application with a browser-based HTML and JavaScript interface.

We are building an AI-powered platform that processes and organizes medical and research information.

The system combines:

- Document intelligence
- OCR
- NLP / Medical NLP
- Medical image analysis
- Multimodal fusion
- RAG
- LLMs
- Structured database storage
- Report comparison
- Patient D health timeline
- Research-paper search and Q&A
- Audit logging

The system is intended to support information retrieval, document understanding, longitudinal record organization and research analysis.
---
## Assistant context
The Assistant retrieves project information from the Markdown and text files in `project_kb/`. When a question names a Patient D, it retrieves that signed-in user's current reports and scan summaries from the database. Those records are not copied into this shared knowledge base.

# Project notes

- AI Assistant: answers questions about the project and about a named Patient D's reports and scan results. It does not diagnose.
- Patient D records are private to the signed-in user.
- Medical image model outputs are experimental and are not confirmed diagnoses.

# How to use the application
The default database is `instance/medical_ai.db`; uploaded documents and scans
are stored under `instance/uploads/`. Back up the whole `instance/` folder.
Set `DATABASE_URL` only when intentionally selecting another persistent
database. If a legacy relative `medical_ai.db` or `app.db` does not exist but
`instance/medical_ai.db` does, the app uses the existing database rather than
silently creating a new empty database next to the project.

# Contributing

Thanks for helping with this project.

## Working rules

- keep changes focused on one module or feature
- read the project overview and module plan before starting
- do not skip tests for the area you changed
- do not commit secrets or environment-specific values
- keep API routes and database changes documented

## Setup

1. clone the repo
2. create a local virtual environment
3. install requirements
4. copy `.env.example` to `.env`
5. run the app and tests locally

## Pull requests

- create a branch for each task
- keep PRs small and clear
- include a short summary of changes and validation steps
- request review before merge

## Security

- never push real credentials
- never store plaintext passwords
- follow the project’s medical-data and privacy rules
